💾 CACHING STRATEGY
──────────────────────────────────────────────────────────────────────────────

LAYER 1: LOCAL STORAGE
  Key Format: "wf:images:{country_lowercase}"
  Value:
    {
      data: [UnsplashImage[], ...],
      ts: 1704067200000
    }
  TTL: 48 hours
  Persistence: Survives browser restart

LAYER 2: MEMORY CACHE
  Type: Map<string, { data: UnsplashImage[], ts: number }>
  TTL: 48 hours
  Persistence: Current session only
  Fallback: If localStorage fails

LAYER 3: API CALLS
  Endpoint: https://api.unsplash.com/search/photos
  Method: GET with query parameters
  Rate Limit: 50 requests/hour (free tier)
  Response: Cached in both storage layers

CACHE INVALIDATION:
  ✓ Manual: clearImageCache(country) function
  ✓ Automatic: 48-hour expiration
  ✓ On Fetch: Check TTL before using cached data


🗄️ DATABASE SCHEMA
──────────────────────────────────────────────────────────────────────────────

CREATE TABLE image_cache (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  country text NOT NULL,
  search_queries jsonb NOT NULL,          ← ["Nepal landmark", "Nepal culture", ...]
  images jsonb NOT NULL,                  ← [{ url, alt, photographer, ... }]
  fetched_at timestamptz DEFAULT now(),   ← When data was fetched
  expires_at timestamptz DEFAULT now() + interval '48 hours',
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now(),
  UNIQUE(country)
);

INDEXES:
  ✓ idx_image_cache_country      ← Fast lookup by country
  ✓ idx_image_cache_expires_at   ← Find expired entries

RLS POLICIES:
  ✓ Public read: Anyone can view cached images
  ✓ Auth insert/update: Only authenticated users can refresh cache

⚙️ API INTEGRATION DETAILS
──────────────────────────────────────────────────────────────────────────────

UNSPLASH API:
  Base URL: https://api.unsplash.com
  Endpoint: /search/photos
  Auth: Query param "client_id"
  Rate Limit: 50 requests/hour
  Response: JSON with array of photo objects

REQUEST EXAMPLE:
  GET https://api.unsplash.com/search/photos?
    query=Nepal+landmark
    &per_page=4
    &client_id=YOUR_API_KEY

RESPONSE STRUCTURE:
  {
    results: [
      {
        id: "abc123",
        urls: { regular: "https://..." },
        alt_description: "Nepal temple",
        user: {
          name: "John Doe",
          links: { html: "https://unsplash.com/@johndoe" }
        },
        width: 1600,
        height: 1200,
        links: { download_location: "..." }
      },
      ...
    ],
    total: 1234,
    total_pages: 50
  }

🆘 TROUBLESHOOTING
──────────────────────────────────────────────────────────────────────────────

ISSUE: Gallery not showing
  CAUSE 1: API key not configured
    FIX: Add VITE_UNSPLASH_API_KEY to .env

  CAUSE 2: API returns 401 (Unauthorized)
    FIX: Regenerate API key from Unsplash dashboard

  CAUSE 3: Unsplash API not reachable
    FIX: Check internet connection, API status

ISSUE: Rate limited error
  CAUSE: Exceeded 50 requests/hour
    FIX: Wait 1 hour or use cached data

ISSUE: Images not loading
  CAUSE 1: CORS error
    FIX: Unsplash CDN should handle CORS. Check fetch response.

  CAUSE 2: Invalid image URLs
    FIX: Check Unsplash API response in Network tab

ISSUE: Cache not persisting
  CAUSE 1: localStorage disabled
    FIX: Check browser privacy settings

  CAUSE 2: Storage quota exceeded
    FIX: Run: Object.keys(localStorage).filter(k => k.startsWith('wf:images:')).forEach(k => localStorage.removeItem(k))

ISSUE: Auto-scroll not working
  CAUSE: Gallery height too small or no scroll room
    FIX: Adjust gallery height in component
